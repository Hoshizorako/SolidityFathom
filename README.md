# SolidityFathom

SolidityFathom provides a high-performance, distributed framework for real-time data processing and analytics on blockchain networks through auto-scaling architecture.

SolidityFathom is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SolidityFathom.git`
2. `cd SolidityFathom`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
